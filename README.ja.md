# R₄(2(x−y)=3z) = 226 — SAT / キューブ分割による計算

**結果(2026-10-21〜22 JST に計算。査読なし):**
方程式 `2(x − y) = 3z` の4色ラドー数は **226** です。

- **R₄ > 225:** 1〜225 を4色で塗って、単色の解が出ない塗り方があります(`results/lower_bound_n225/`。わざと素朴に書いた別チェッカで検証)。
- **R₄ ≤ 226:** 1〜226 にはそのような4色の塗り方がありません。キューブ分割で14,162個すべて UNSAT。
  各キューブを CaDiCaL で解き直して DRAT 証明を作り、`drat-trim` が 14,162 / 14,162 件を受理しました。

これまで公開されている表(arXiv:2210.03262 の Table 10)では、この方程式は `>225` という下限だけです。
調べた範囲では厳密な値の公表は見つかりませんでした(下の「文献状況」参照)。
**これは小さな具体的な計算結果で、P vs NP とは関係ありません。**

保存版(Zenodo、全版共通): https://doi.org/10.5281/zenodo.23565747

定義: `R_k(E)` は、{1,…,n} のどの k 色塗りにも、E の単色の解 (x, y, z)(正の整数、n 以下、同じ値でもよい)が
存在するような最小の n です。

論文の LaTeX ソースは `paper/main.tex` です(ビルド: `./3_build_paper.bat`、または Overleaf にアップロード)。

## 再現手順(Windows の PowerShell、Python 3)

```
./0_check_lower_bound.bat      # 数秒: 1〜225 の塗り方を検証
./1_search_n226.bat            # 11コアで数時間: キューブ探索(再開可。事前に pip install python-sat)
./2_check_proofs.bat           # 11コアで約1時間: キューブごとに DRAT 証明を検証(WSL と bin_linux/ が必要)
```

私の実行結果はすべて `results/` に入っています(キューブごとの結果と JST 時刻、`FINAL.txt`)。
DRAT 証明ファイルそのものは大きいので含めていません(手順2で再生成されます)。

## この結果が頼っているもの(弱くなりうる点)

1. CNF(`tools/rado_c1.py` の `build_cnf`)が問題を正しく表していること。小さい場合の総当たり、既知の値
   (シュア数、R₄(x−y=2z)=171、arXiv:2210.03262 Thm 1.2 の3色の値)の再現、n=225 の塗り方の別チェッカでの検証で確認。
2. 対称性除去(色を最初に使う順に番号付け)が妥当であること。議論による確認で、機械検証はしていません。
3. キューブの一覧が完全であること。深さ10の「単色の解を含まない標準形の先頭部分」の数 14,162 を、別の総当たりで数え直して一致。
4. `drat-trim` が正しいこと。広く使われていますが、形式検証されたチェッカ(cake_lpr など)での再確認は未実施です。
