# R₄(2(x−y)=3z) = 226  — a SAT / cube-and-conquer computation

**Result (computed 2026-10-21/22 JST, not peer reviewed):**
the 4-colour Rado number of the equation `2(x − y) = 3z` is **226**.

- **R₄ > 225:** a 4-colouring of {1,…,225} with no monochromatic solution exists
  (`results/lower_bound_n225/`, checked by a deliberately naive independent checker).
- **R₄ ≤ 226:** no such 4-colouring of {1,…,226} exists. Shown by cube-and-conquer: 14,162 cubes, all UNSAT;
  every cube was re-solved with CaDiCaL producing a DRAT proof that `drat-trim` accepted (14,162 / 14,162 VERIFIED).

Before this, the published table (Table 10 of *Rado Numbers and SAT Computations*, arXiv:2210.03262, Chang–De Loera–Wesley)
lists only the lower bound `> 225` for this equation. As far as I could find (see *Literature status* below),
the exact value has not been published. **This is a small, specific computational result. It says nothing about P vs NP.**

Archived copy (Zenodo, release v1.0): https://doi.org/10.5281/zenodo.23565748

Definitions: `R_k(E)` is the smallest `n` such that every k-colouring of {1,…,n} contains a monochromatic solution
`(x, y, z)` of `E` in positive integers ≤ n (the variables need not be distinct).

The write-up (LaTeX source) is in `paper/main.tex` (build: `./3_build_paper.bat`, or upload to Overleaf).

## Reproduce (Windows, PowerShell; Python 3)

```
./0_check_lower_bound.bat      # seconds: validates the colouring of 1..225
./1_search_n226.bat            # hours on ~11 cores: cube search, resumable (needs: pip install python-sat)
./2_check_proofs.bat           # ~1 h on 11 cores: DRAT proof per cube, needs WSL + bin_linux/ (see bin_linux/README.md)
```

All results of my own run are included: `results/cube_search_n226/` (per-cube status with JST times, `FINAL.txt`),
`results/proof_check_n226/` (per-cube `VERIFIED` rows, `FINAL.txt`). The DRAT proof files themselves are not included

## What the result depends on (possible weak points)

1. The CNF (`tools/rado_c1.py: build_cnf`) correctly encodes the problem. Evidence: agrees with brute force on small cases,
   reproduces known values (e.g. Schur numbers, R₄(x−y=2z)=171, and the 3-colour theorem values of arXiv:2210.03262 Thm 1.2),
   and the n=225 colouring is validated by the independent checker.
2. The symmetry breaking (colours numbered in order of first use) is valid: every colouring can be recoloured into this form.
   Argued, not machine-checked.
3. The cube list is complete: depth-10 canonical prefixes without a monochromatic solution; their number (14,162) was
   recounted by a separate brute-force enumeration (`verify_proofs.py: brute_cover`).
4. `drat-trim` is correct. It is widely used but was not cross-checked with a formally verified checker (e.g. cake_lpr).
   A cross-check is a natural next step.

## Literature status (checked 2026-10-22 JST; not exhaustive)

- arXiv:2210.03262 (only version v1, 2022-10-07): Table 10 gives `>225` for this equation.
- A student report from the same group and arXiv:2505.12085 treat only 3 colours / other equations; neither mentions 226.
- Not done yet: list of papers citing arXiv:2210.03262, and asking the authors. If you know of a published value, please open an issue.

```
tools/        rado_c1.py (CNF), rado_verify.py (independent colouring checker),
```

Note on code versions: `tools/` holds the current versions of the scripts. The recorded run used an earlier `cube_search.py`; the later changes only add an optional `--split` mode (off by default), so the default behaviour is unchanged.
